# wocli-music v0.4.4

Windows 音频输出设备热插拔跟随与蓝牙断开自动恢复修复。

- 修复 Windows 音频输出设备跟随：动态侦测操作系统默认音频端点变动，解决 Windows 系统切换播放设备（如扬声器 / 耳机）时 `wocli` 无法随之切换、必须重启守护进程的问题。
- 蓝牙耳机断开保护：增加声卡硬件回调停顿监测（`AUDCLNT_E_DEVICE_INVALIDATED` 防护），当蓝牙断开或耳机拔出时自动暂停播放，防止扬声器公放。
- 无缝设备迁移续播：在设备切换后用户恢复播放（或切歌）时，自动在新默认输出设备上从当前进度平滑续播，告别耳机和扬声器只能“二选一”的困扰。
- 播放状态扩展：在 `wocli status` 状态输出中新增 `audio_device` 字段，方便掌握当前正在使用的物理音频输出设备名称。

升级：`wocli update`，完成后运行 `wocli restart` 即可。
