# 0.4.11-alpha.2：Windows 原生歌词卡片开发预览

本版将 alpha.1 的 Feed 公告改为微软官方 **Adaptive Card 小组件**。按 `Win+W` 展开 Windows 小组件面板后，可以查看当前歌词，并操作上一首、暂停／继续和下一首。字体、颜色和按钮由 Windows 渲染。

普通卡片不依赖 Feed／Web Widget 的 EEA 地区能力，清单没有排除中国地区。它需要可用的 Windows 11 Widgets 面板，**不会替换任务栏天气文字，也不提供关闭面板后的常驻歌词**。这是用户确认采用的官方面板方案。

## 功能与修复

- 提供小、中、大尺寸卡片；小卡片保留暂停／继续按钮，中、大卡片提供三个播放按钮。歌曲和歌词按纯文本显示，不把内容解释为网页或 Markdown 链接。
- 活跃卡片每 500ms 读取轻量歌词快照，只在内容变化时更新。停用后清空旧内容并停止实时读取；删除后释放实例状态。
- 暂停时保留当前歌词及继续按钮。停止、老板模式、关闭歌词、切换曲库和失联时清除歌曲信息。
- 播放按钮绑定当前歌曲和状态，播放器原子校验后执行；过期卡片不能误操作新歌，不能退出老板模式，也不能发送任意命令。
- 限制通信时间、文件和回复大小，使用单个后台循环及歌词缓存。诊断不记录歌词、歌曲名或授权令牌。
- `widgets status` 明确区分卡片组件和旧 Feed 心跳；启用系统模式后不会自动恢复旧 GDI 歌词条。

## 安装与使用

下载 Windows x64 ZIP 并完整解压到固定目录，先阅读 `PREVIEW.txt`。包内包含配套 `wocli.exe`、`Layout`、微软签名运行库、未签名 MSIX、校验和及第三方许可／源码。

这是开发注册包，**未签名 MSIX 不能直接双击安装**。在已有开发者模式的环境中，按 `PREVIEW.txt` 安装 `Dependencies` 里的微软框架，再注册 `Layout/AppxManifest.xml`。已安装 alpha.1 的用户按同一说明替换旧开发注册；随后重新添加普通歌词卡片。

从旧版升级前，先退出旧 TUI，并使用包内播放器执行 `./wocli.exe tray stop` 和 `./wocli.exe daemon stop`，关闭旧托盘及旧后台，避免仍由旧版本处理歌词请求。然后使用包内播放器：

```powershell
.\wocli.exe widgets on
.\wocli.exe play "歌名 歌手"
.\wocli.exe widgets status --json
```

按 `Win+W`，通过小组件选择器添加 **wocli 歌词**。关闭：`./wocli.exe widgets off`。组件不会自动启动音频后台或播放音乐；卸载方式见 `PREVIEW.txt`。

## 验证边界

自动测试与 Windows CI 检查卡片、通信、生命周期、播放守卫、构建、MSIX、包注册身份和 COM 激活。COM 测试使用同进程临时类，尚未验证跨进程代理通信或真实 Widgets 宿主。目标电脑的中文布局、主题、高对比度、DPI、休眠恢复和长时间内存也需实机检查，因此本版作为开发预览发布。签名安装包／商店分发尚未完成，稳定版仍为 0.4.10。

详细说明见 [Windows 系统歌词小组件](../windows-taskbar-lyrics.md)。
