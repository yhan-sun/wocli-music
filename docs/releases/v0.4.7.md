# wocli-music v0.4.7

新增跟随音乐的频谱动效，并优化播放界面和每日推荐体验。

- TUI 按 `Shift+V` 开关频谱，显示实际播放音频的低高频变化，峰值上升后逐渐下落；暂停和缓冲时自然回落。
- 频谱采样使用有界缓冲并在独立线程分析；终端高度不足时隐藏，静音测试输出不产生频谱。
- 播放栏将歌曲、状态、控制与进度分层展示，窄终端也能看到歌曲和主要控制。
- 每日推荐增加本地/在线状态、空列表和刷新提示；按 `u` 可查看并恢复已排除的歌曲。
- macOS 与 Windows 托盘播放日推失败时显示提示。

升级：`wocli update`。频谱依赖新版后台；如果升级后后台仍在运行，执行 `wocli daemon stop`，然后重新播放。托盘可通过 `wocli tray start` 重新启动。
