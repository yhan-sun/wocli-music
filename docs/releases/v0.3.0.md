# Release v0.3.0

wocli-music v0.3.0 是项目架构成熟度的重大飞跃：实现了真正的毫秒级渐进流式播放（首播延迟 < 200ms）、有界后台工作线程池与连接限流门禁、Vim 风格终端键盘导航、100% 纯 Rust 架构（彻底告别 Python 历史遗留），并提供全面的英文国际化文档。

### 核心亮点

1. **毫秒级渐进流式播放 (Progressive Audio Streaming)**：
   - 告别以往“先完整下载再播放”的模式。
   - 引入原子通知与条件变量驱动的 `ProgressiveReader`，仅需预缓冲 128KB 即可由 Symphonia 解码器瞬间起播，首播/切歌延迟缩短至 200ms 以内。
   - 边播边下、后台静默缓冲，断网与异常自动回退。

2. **有界线程池与客户端并发限流 (Bounded Concurrency & Daemon Resiliency)**：
   - 引入固定容量轻量工作线程池 `WorkerPool`，杜绝后台无界 `thread::spawn`。
   - 引入基于原子 CAS 操作的高并发连接限制器 `ConnectionLimiter`（默认最大 16 并发客户端），彻底防止 IPC 客户端泛洪与连接泄露。

3. **100% 纯 Rust 架构 (Legacy Python Completely Purged)**：
   - 彻底删除旧版 `src/wocli_music/`、`pyproject.toml` 及陈旧脚本，代码库瘦身 5,100+ 行。
   - 单一跨平台二进制，macOS ARM64 压缩包仅约 2.2 MB。

4. **键盘优先与 Vim 风格终端交互 (Keyboard-First & Vim Navigation)**：
   - 支持 `j` / `k` 上下移动曲目。
   - 支持 `g` / `G` 快速跳转至列表顶部 / 底部。
   - 支持 `[` / `]`（或 `<` / `>`）快速切换上一首 / 下一首曲目。
   - 支持 `Ctrl+U` / `Ctrl+D` 半屏 / 翻页滚动。

5. **国际化与英文文档 (Internationalization)**：
   - 新增面向全球开源社区的 `README_EN.md`。
