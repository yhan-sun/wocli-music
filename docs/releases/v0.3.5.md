# wocli-music v0.3.5

安装和自更新默认使用 Cloudflare 分发入口 https://wocli.yhan.fun/，国内用户无需直连 GitHub 即可获取安装器、版本信息、四个平台安装包和对应源码。

- 新版 `wocli update` 使用分发服务并保留 SHA256 校验；可通过 `WOCLI_DOWNLOAD_BASE=github` 切回 GitHub。
- 旧版客户端若无法更新，重新运行官网的一键安装命令即可，保留曲库和设置。
- 分发仅代理本项目的发行文件，服务端完成 GitHub 文件跳转，版本缓存 10 分钟，安装包与源码缓存 24 小时。
- 安装器严格校验版本和 SHA256；Windows 保留 PowerShell 5.1 所需 UTF-8 BOM，并同步当前终端 PATH。
- 新增本地 stdio MCP：`wocli mcp serve` 提供 17 个播放器工具，`wocli mcp config` 生成客户端配置；`--read-only` 开放 8 个查询工具。
- MCP 复用原播放器后台与曲库，提供搜索、播放、队列、收藏、歌单、歌词、下载和已有音源操作；支持结构化结果、请求取消、大小及并发限制。

普通 Cloudflare 全球网络的大陆可达性和速度取决于运营商线路；本服务并未开通 Cloudflare China Network。缓存分发依赖 GitHub 上游。

详细文档：[分发配置](https://github.com/yhan-sun/wocli-music/blob/main/docs/distribution.md)、[MCP](https://github.com/yhan-sun/wocli-music/blob/main/docs/mcp.md)。

本发行版为原生 Rust 程序，运行无需 Python、Node.js、mpv 或 FFmpeg。
