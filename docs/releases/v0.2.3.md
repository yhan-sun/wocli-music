# wocli-music v0.2.3 — 系统任务栏小图标与实时任务栏歌词

本版本为 macOS 和 Windows 用户带来了原生系统托盘图标控制及实时任务栏歌词显示支持，并大幅扩充和完善了切歌与快捷控制指令集。

### 核心亮点

#### 1. 系统托盘小图标控制 (macOS Menu Bar / Windows System Tray)
- **快捷交互**：左键点击图标快速切换播放/暂停；右键弹出原生菜单展示当前曲目、歌手、进度及实时歌词。
- **全能控制**：提供播放/暂停、上一首、下一首、播放模式循环切换（列表循环/单曲循环/随机播放/顺序播放）、音量调节（+10%/-10%）、打开终端播放器与安全退出。
- **服务守护**：通过 `wocli tray start|stop|status` 独立启停，或在 `wocli daemon start` 时自动跟随启动。

#### 2. 系统任务栏 / 状态栏实时歌词 (Taskbar Lyrics)
- **macOS 状态栏歌词**：状态栏小图标直接展示当前正在演唱的实时歌词（如 `🎵 刮风这天我试过握着你手`），抬头即可浏览歌曲进度。
- **Windows 任务栏歌词条**：采用原生 Win32 分层透明置顶窗口，具备鼠标穿透（`WS_EX_TRANSPARENT`）特性，悬浮于任务栏上方居中展示高对比度阴影描边歌词，完全不阻碍底层任务栏和窗口操作；同时在托盘悬停 Tooltip 中实时更新多行歌词。
- **随心开关**：支持 `wocli lyrics-bar on/off/toggle/status` 随时开关或在托盘菜单直接切换。

#### 3. 命令完善与别名扩展
- **切歌与跳转**：
  - `wocli next` / `wocli skip`：下一首（默认等待加载完成并输出新曲目信息，支持 `--no-wait` 异步切换）。
  - `wocli prev` / `wocli previous`：上一首。
  - `wocli play-pause` / `wocli toggle`：播放/暂停。
- **任务栏歌词控制**：
  - `wocli lyrics-bar [on|off|toggle|status]`
- **托盘服务管理**：
  - `wocli tray [start|stop|status|run]`

### 一键安装与升级

#### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/yhan-sun/wocli-music/main/install.ps1 | iex
```

#### macOS / Linux (Shell)
```bash
curl -fsSL https://raw.githubusercontent.com/yhan-sun/wocli-music/main/install.sh | bash
```
