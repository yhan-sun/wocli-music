# wocli-music v0.4.3

macOS 菜单栏与 Windows 任务栏播放控制按钮组升级。

- macOS 菜单栏快捷控制：新增常驻的上一首（⏮）、播放/暂停（▶/⏸ 动态图标与 Tooltip）与下一首（⏭）单色模板按钮，支持在状态栏直接一键单击切歌与暂停，无需展开下拉菜单。
- macOS 菜单栏控制配置与联动：新增「菜单栏控制按钮: 开启 / 关闭」菜单项；进入老板模式（Ctrl+Shift+B）时自动随歌词同步隐身。
- Windows 任务栏控制按钮显示门槛优化：将按钮展示宽度限制从 260dp 降低至 180dp，适配 Windows 11 默认图标居中及高 DPI 缩放场景下的窄任务栏空间。
- Windows 任务栏命中测试修复：重构 `button_at` 判定逻辑，加入垂直 Y 轴边界与边缘距离校验，杜绝按钮垂直区域外的无效触发与误触。

升级：`wocli update`，完成后运行 `wocli tray restart` 即可享受全新菜单栏与任务栏控制体验。
