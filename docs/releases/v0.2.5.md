# Release v0.2.5

wocli-music v0.2.5 移除了所有 emoji 图标，重构为符合 macOS / Windows 系统原生美学的干净排版，并为 macOS 状态栏引入原生 SF Symbol 矢量单色模板图标。

### 核心改进

1. **全面移除 Emoji 符号**：
   - 彻底移除 macOS 状态栏标题与弹出菜单中的所有彩色 emoji 符号（`🎵`、`⏸`、`▶`、`🔄`、`🔊`、`💬`、`🖥`、`🚪`）。
   - 移除 Windows 任务栏通知区菜单与歌词条中的 emoji 前缀。
   - 所有菜单项重构为现代系统原生排版，文字整齐紧凑、专业大方。

2. **macOS 接入原生矢量模板图标 (SF Symbol)**：
   - 状态栏图标采用 Apple 官方 SF Symbol 单色矢量模板（`music.note`）。
   - 支持 macOS 浅色/深色模式自动变色（Template Image），与微信、Wi-Fi、控制中心等系统级图标风格完全统一。

### 下载与安装

- **macOS / Linux**:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/yhan-sun/wocli-music/main/install.sh | bash
  ```

- **Windows 10/11**:
  ```powershell
  irm https://raw.githubusercontent.com/yhan-sun/wocli-music/main/install.ps1 | iex
  ```
