# wocli-music v0.4.9

完善 Windows 原生任务栏歌词，修复窄屏交互和播放状态一致性问题。

- Windows 歌词继续使用 Rust + Win32/GDI 子窗口绘制，无需 WebView2 或 .NET。修复镜像坐标、左侧通知区、DPI 与窗口样式刷新，并回读实际布局以避免遮盖任务栏按钮。
- 托盘 IPC 改为后台串行处理，修复右键菜单重入、后台无响应时界面卡住、连续音量/模式操作丢失，以及退出时强杀自身导致任务栏空间未恢复的问题。
- 控制按钮整个按钮面可点击，双击按钮不再误开终端；打开终端沿用当前曲库目录，停止或连接过期后清理旧歌词和歌曲提示。
- 修复 TUI 窄屏标题重叠、最小窗口搜索结果不可见、弹窗空白误关闭、隐藏侧栏焦点、搜索分页及异步选中项错乱。
- 全屏歌词页不再误删背后列表的歌曲，硬件播放/暂停键保留未保存输入，进度百分比避免零除和乘法溢出。
- 修复设备重连的旧结果覆盖暂停/跳转、暂停时网络重试或删除当前歌曲意外出声、无效播放请求破坏队列、随机播放历史和歌词重试状态。
- 下载校验实际解码长度以拒绝截断文件，Windows 音频设备查询配对释放 COM 初始化引用。

升级：运行 `wocli update`。升级后执行 `wocli daemon stop` 和 `wocli tray stop`，再运行 `wocli tray start` 并重新播放，以确保后台与托盘使用新版本。曲库与设置继续保留。

Windows 任务栏嵌入依赖 Explorer 窗口结构和 UI Automation，目前仅覆盖主任务栏的横向布局；空间或边界信息不足时隐藏。自动测试包含原生隔离窗口场景，不能替代真实 Windows 10/11 Explorer、多屏和混合 DPI 的实机验收。详细方案与验收步骤见 [Windows 任务栏歌词说明](https://github.com/yhan-sun/wocli-music/blob/v0.4.9/docs/windows-taskbar-lyrics.md)。
