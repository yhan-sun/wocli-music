# wocli-music v0.2.2 — Windows 稳定常驻与网络连接优化

本版本修复在实机 Windows 环境（Windows 11 / Server）测试中发现的后台守护进程生命周期与套接字非阻塞继承问题：

### 关键修复与改进
1. **修复 Windows 套接字非阻塞继承 (WSAEWOULDBLOCK 10035 / WSAECONNRESET 10054)**
   - 在 Winsock 中，非阻塞监听套接字 `accept()` 出的连接套接字会继承非阻塞模式。
   - 现显式将接受的客户端套接字恢复为阻塞模式，彻底避免在读取鉴权令牌或高频状态轮询时的偶发连接中断与重置。

2. **强化 Windows 后台进程托管生命周期**
   - 采用 `Invoke-CimMethod -ClassName Win32_Process -MethodName Create` 彻底解耦调用方控制台与 Windows Job Object。
   - 解决在 SSH 会话、终端标签页关闭或脚本退出时，后台音乐播放被操作系统误杀的问题。

3. **显式 `--home` 目录传递**
   - CLI 支持 `--home <path>` 选项并在启动守护进程时显式传递，消除无环境变量继承场景下的路径解析歧义。

### 安装与升级

#### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/yhan-sun/wocli-music/main/install.ps1 | iex
```

#### macOS / Linux (Shell)
```bash
curl -fsSL https://raw.githubusercontent.com/yhan-sun/wocli-music/main/install.sh | bash
```
