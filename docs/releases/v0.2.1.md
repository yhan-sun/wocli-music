# wocli-music v0.2.1 — 原生 Windows 支持与安装脚本

在 v0.2.0 原生 Rust 播放器的基础上，实现完整的 Windows 原生支持，并新增跨平台一键安装脚本体系与环境变量规范。

- **原生 Windows 支持**：无需 WSL 或 Cygwin，直接在 Windows 10/11 (x86_64 / ARM64) 原生运行 `wocli.exe`。
- **跨平台 IPC 通信**：Unix 下保持 Unix Domain Socket，Windows 下采用安全的本地回环 TCP 与一次性动态令牌授权机制。
- **Windows 独立后台守护**：Windows 下通过进程解耦与无窗口模式常驻后台，关闭终端后音乐不中断，随时通过其他终端连入控制。
- **全新一键安装器**：
  - macOS / Linux：`curl -fsSL https://raw.githubusercontent.com/yhan-sun/wocli-music/main/install.sh | bash`
  - Windows PowerShell：`irm https://raw.githubusercontent.com/yhan-sun/wocli-music/main/install.ps1 | iex`
  - 均支持自动检测系统、校验 SHA256 签名并自动配置 PATH 环境变量。
- **全平台 3MB 内超轻量级发行包**：Windows `.zip` 压缩包仅约 3.0 MB，macOS / Linux `.tar.gz` 仅约 2.1~2.6 MB。
- **完善环境变量体系**：支持 `WOCLI_HOME`、`WOCLI_RUNTIME_DIR`、`WOCLI_DOWNLOAD_DIR`、`WOCLI_AUDIO_OUTPUT` 等，并通过 `wocli doctor` 导出完整运行期诊断状态。

下载与你系统对应的安装包解压运行即可，普通用户**无需下载 `-sources`**。校验值见 `SHA256SUMS`。
