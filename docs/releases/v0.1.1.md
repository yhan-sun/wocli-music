# wocli-music v0.1.1

现在可以下载解压直接运行。二进制包内置 Python 运行时、mpv、证书和动态库，用户无需安装 Python、uv 或 mpv。

## 下载与运行

| 系统 | 文件 |
| --- | --- |
| macOS 15+，Apple Silicon | `wocli-music-0.1.1-macos-arm64.tar.gz` |
| macOS 15+，Intel | `wocli-music-0.1.1-macos-x86_64.tar.gz` |
| Linux x86_64，glibc 2.35+（如 Ubuntu 22.04+） | `wocli-music-0.1.1-linux-x86_64.tar.gz` |

例如 Apple Silicon Mac：

```bash
tar -xzf wocli-music-0.1.1-macos-arm64.tar.gz
cd wocli-music-0.1.1-macos-arm64
./wocli
```

保留整个解压目录，`_internal` 中有必需的运行库。其他系统使用对应文件名，启动方式相同。

macOS 包采用临时签名，尚未通过 Developer ID 公证；若系统拦截，先核对校验值，再按 [README 中的说明](https://github.com/yhan-sun/wocli-music#安装)允许该应用。Linux 使用系统已有的音频设备与声音服务。

## 本次更新

- GitHub Actions 自动构建三种平台包，全部验证通过后发布。
- 修复冻结程序的后台启动方式，CLI / 界面退出后后台播放继续。
- 自动优先使用包内 mpv；HTTPS 证书随包分发。
- 在实际解压的包中验证 CLI、TUI、播放、暂停、跳转、歌词、收藏夹和播放方式。
- Linux 额外在没有 Python、mpv、网络的干净容器中验证本地播放。

仍保留 wheel 与 Python 源码包，供现有 Python 环境使用。各平台的 `*-sources.tar.gz` 为原生依赖对应源码，不是运行程序所必需；许可与来源信息也保存在二进制包的 `licenses/` 中。

`SHA256SUMS` 包含全部八个归档文件的校验值。下载完整文件集后，macOS 用 `shasum -a 256 -c SHA256SUMS`，Linux 用 `sha256sum -c SHA256SUMS`。只下载部分文件时，计算单个文件的 SHA-256 并对照清单即可。

按 `/` 搜索、Enter 播放、`c` 收藏、`m` 切换播放方式、`?` 查看帮助。退出界面后继续播放；停止音乐执行 `./wocli stop`，停止后台执行 `./wocli daemon stop`。上游部分歌曲或音质仍可能无法取得完整版。
