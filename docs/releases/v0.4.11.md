# wocli-music v0.4.11

修复 macOS 从托盘退出后播放后台仍在运行的问题，并完善退出确认和失败重试。

- 托盘菜单改为“退出播放器”：先停止播放和下载，等待后台清理完成，再关闭托盘、歌词和系统播放信息。修复此前先向托盘自身发送终止信号、导致后台关闭请求未执行的问题。
- macOS 托盘与 Windows 共用异步串行 IPC。后台请求不再阻塞菜单；退出期间显示进度，失败时保留入口供重试，连续音量、播放模式和歌词开关操作按顺序处理。
- `wocli daemon stop` 先关闭播放后台，再确认托盘退出；`wocli tray stop` 等待托盘实际结束，清理进程与快捷键状态，支持立即重新启动。
- 后台清理期间重复停止仍会等待完成；旧后台来不及返回确认便断开连接时，通过后台锁核实实际退出。退出失败不再静默报告成功。
- 更新安装脚本的备用版本，并补充退出确认、超时、自终止防护和托盘重启回归测试。

升级：

```sh
wocli update
```

曲库与设置保留。升级后使用菜单中的“退出播放器”可关闭播放后台和托盘。`wocli stop` 停止播放，`wocli tray stop` 仅关闭托盘；终端按 `q` 退出界面后，播放与下载仍在后台继续。

AI 客户端启动的 stdio MCP 连接进程由客户端管理，与播放后台独立。
