# wocli-music v0.2.0 — Rust 原生播放器

用 Rust 替换 Python、Textual、mpv 与 FFmpeg，直接使用原生音频解码与系统输出。macOS ARM64 本地完整安装包约 2.2 MB，比 v0.1.1 的 38.1 MB 显著缩小；各平台最终大小见附件。

- 保留搜索、本地音频、后台播放、同步歌词、我喜欢、收藏夹、队列、历史、四种播放方式及下载。
- 紧凑搜索、两行底栏、可点击/拖动进度条；列表和歌词均有明确的「收藏到…」。
- 歌曲与歌词独立加载/重试；切歌隔离过期请求，拒绝明显试听与不完整音频。
- 原生解码 MP3、FLAC、AAC/M4A、WAV；后台不再启动 mpv 子进程。
- SQLite 数据格式兼容旧版，继续读取原来的收藏、历史、队列、设置和歌词缓存。
- Actions 构建 macOS ARM64 / Intel、Linux x86_64；实际解压产物通过 CLI、TUI、解码、后台、跳转、歌词和收藏测试后发布。

下载与你系统对应的 `wocli-music-0.2.0-平台.tar.gz` 即可，**无需下载 `-sources`**。源码附件仅提供第三方许可要求的依赖源码，体积也远小于旧版 mpv/FFmpeg 源码包。校验值见 `SHA256SUMS`。

升级前用旧命令停止旧版后台，再运行新二进制。macOS 可单独复制 `wocli`；Linux 保留 `lib/` 在可执行文件旁。macOS 15+；Linux x86_64 / glibc 2.35+，播放使用系统已有的音频配置。

当前在线播放先缓存完整音频并检查后开始，慢网络或 FLAC 首次加载会更久。上游曲目可用性不由客户端保证；无账号歌单同步、Windows 后台、封面与系统媒体键。
