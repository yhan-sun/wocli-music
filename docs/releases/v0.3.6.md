# wocli-music v0.3.6

MCP 接入现在有明确的启动提示和可复制给 AI 的提示词。

- 在终端运行 `wocli mcp serve` 会显示“启动成功，正在等待 AI 客户端连接”和“复制下面的提示词给 AI”，附上本机程序、曲库路径及接入步骤。
- 新增 `wocli mcp prompt`，无需保持终端会话运行，输出后即可复制给支持本地 stdio MCP 的 AI 客户端；支持只读、直连、自定义曲库和 JSON 输出。
- 提示词引导 AI 保留已有配置、连接后列出工具并查询播放状态，无配置权限时说明设置步骤。
- 等待握手时支持 Ctrl+C 退出；客户端通过管道启动服务时保持安静，stdout 只输出 MCP 协议报文。
- 完善中英文 README、命令帮助及 MCP 文档，并验证真实终端显示、连接和退出。
- 分发服务同步修复 Windows PowerShell 5.1 的版本查询，以及 `irm … | iex` 对 HTTP 安装脚本 BOM 的解析问题。

已有用户运行 `wocli update` 即可升级，安装和更新默认通过 [分发入口](https://wocli.yhan.fun/) 获取文件并验证 SHA256，保留原曲库和设置。

详细文档：[MCP 接入](https://github.com/yhan-sun/wocli-music/blob/main/docs/mcp.md)。
