# wocli-music v0.3.8

新增歌单文件迁移与固定虚构身份的老板代码视图。

- 导入 CSV/TSV/TXT、wocli JSON v1、LX **单歌单 v2**（`.lxmc`/JSON）、MusicFree 多歌单备份、M3U/M3U8/PLS、JSPF；导出 JSON/CSV/TSV/TXT/M3U8/JSPF。
- `wocli playlist import 文件 --name "新名称"`；支持 `--dry-run`、`--offline`、`--list` 和 `--on-conflict rename|error|merge|replace`。默认同名另存。
- 原平台 ID 不直接用于播放；核对歌名、歌手和版本后匹配酷我或本地歌曲。未匹配与多个候选保留，可用 `inspect` / `resolve` / `match` / `drop` 修复。
- 合并、替换与修复前保存快照：`playlist backups 名称` / `playlist restore 名称 --id 编号`。导入使用事务，取消不留下半张歌单。
- TUI 按 `I` 导入、`E` 导出；多歌单选择、进度、Esc 取消、预览确认，以及歌单 `⋯` 菜单重试匹配。
- 老板伪装使用 ATLAS 虚构身份，展示带行号的 Rust 工程代码、诊断与构建测试日志。**不读取真实用户名、主机名或个人路径**。快捷键保持 Shift+B / Ctrl+B / F12，恢复用 b/B、Ctrl+B、F12 或 Esc。

导入仅迁移曲目信息，不会自动下载音频。JSON 保存完整匹配信息；CSV/TXT/JSPF 用于交换元数据；M3U8 导出需本地文件。在线歌单分享链接、旧版/全量 LX、Apple XML/XSPF 和 Spotify 账号 JSON 尚未支持。MusicFree 备份中的插件不会安装。

[完整导入说明](https://github.com/yhan-sun/wocli-music/blob/main/docs/playlist-import.md)

运行 `wocli update` 升级后退出并重开 TUI；手工替换二进制时先运行 `wocli daemon stop` 以退出旧后台。
