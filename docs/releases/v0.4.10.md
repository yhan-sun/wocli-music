# wocli-music v0.4.10

补齐 UI/UX、后台资源边界和 Windows 原生托盘生命周期的第二轮修复。

- 后台工作队列最多等待 64 项，满时立即反馈；独立流下载连接最多 8 个。预缓冲等待每 50ms 检查取消，设备重置立即取消旧解码器。
- 已结束下载记录最多保留 100 项，未完成下载仍限制 10 项；取消/重试不再重复积压队列，重试也遵守容量限制。
- Windows 托盘图标注册、提示更新失败后自动重试；多个 `--home` 实例找到各自窗口正常退出并恢复任务栏布局；避免销毁共享系统图标。
- 托盘推荐最多一个在途请求；托盘与 CLI 的推荐播放使用一次性凭据，等待期间的手动播放、暂停、停止、跳转和队列操作会取消旧推荐。
- 长搜索词、目录和收藏夹名输入显示尾部；30×16 导入弹窗可见错误；帮助支持滚动；滚轮操作指针所在面板；侧栏与全屏歌词不再误改隐藏列表。
- 频谱分析包含全部声道，修复单侧音频的显示。

升级并重启后台：

```powershell
wocli update
wocli daemon stop
wocli tray stop
wocli tray start
```

随后重新播放。曲库与设置保留。

任务栏歌词继续使用 Rust + Win32/GDI 原生子窗口，无需 WebView2 或 .NET。真实 Windows 10/11 Explorer、多屏、混合 DPI、输入法和长时间运行仍需要实机验收；自动测试不能证明所有环境均无问题。正在阻塞的网络读取仍可能等到连接返回或最长 120 秒超时，取消等待及时返回且连接数量受限。
