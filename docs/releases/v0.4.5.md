# wocli-music v0.4.5

新增实验性的每日推荐，基于本地收藏、歌单和最近播放生成每天的私人歌单。

- TUI 侧栏打开「每日推荐」，按 `r` 在线刷新，可播放、加入队列或排除歌曲。
- CLI 支持 `wocli daily`、`daily play`、`daily add`、`daily dislike --id ID` 和 `daily undo --id ID`。
- MCP 支持读取、刷新、播放和管理推荐；只读模式仅查看已有快照。
- macOS 菜单栏和 Windows 托盘菜单增加「播放每日推荐」，使用同一份快照。
- 每首歌提供推荐理由；在线刷新搜索最多三位常听歌手，失败时使用可用的本地候选。

推荐记录保存在本地。在线刷新会向酷我搜索发送歌手名称；播放可用性取决于音源。历史记录表示歌曲加载成功，不代表完整收听。空曲库请先收藏歌曲或导入歌单。

升级：`wocli update`。托盘如果已经运行，升级后执行 `wocli tray stop` 再执行 `wocli tray start`。
