# wocli-music v0.3.1

本次发布新增命令行自更新，并修复流式播放、坏歌跳过和 Windows 安装后的 PATH 问题。

## 自更新

```bash
wocli update --check
wocli update
```

自动识别 macOS ARM64 / Intel、Linux x86_64、Windows x86_64，下载最新稳定发行包并严格校验 SHA256。更新当前实际安装位置，保留曲库、收藏、队列与设置；兼容 Linux 启动包装脚本及配套 ALSA 库，并处理 Windows 运行中文件替换。支持 `--force` 重新安装、`--json` 和 `--direct`。

更新时运行中的后台和托盘会重新启动，播放需要重新开始。首次从 v0.3.0 或更早版本升级，请重新执行安装命令，之后即可使用 `wocli update`。

## 播放修复

- 解码与跳转准备移出后台控制循环，等待网络缓冲时仍可暂停、停止和切歌；跳转等待最多 10 秒。
- 修复本地音频向后跳转失败，以及暂停中连续跳转的状态处理。
- 修复流式下载的 10 秒总请求超时、尾部提前 EOF 和失败缓存阻断下载回退。
- 校验长度、试听片段与 MD5；下载中断会通知播放服务并重试一次。
- 无法播放或解码提前中断的曲目自动跳过，适用于所有播放模式；整个队列失败后停止并保留错误，避免单曲/列表循环反复尝试坏歌。

## Windows 安装

每次安装及重装都会同步用户和当前 PowerShell 的 PATH，并广播环境变更；安装后检查 `wocli` 命令与程序版本。新增 PowerShell 7 和 Windows PowerShell 5.1 的离线安装/重装验证。

## 安装

macOS / Linux：

```bash
curl -fsSL https://raw.githubusercontent.com/yhan-sun/wocli-music/main/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://raw.githubusercontent.com/yhan-sun/wocli-music/main/install.ps1 | iex
```

发行包附带依赖声明与相应源码包；运行无需 Python、mpv 或 FFmpeg。
