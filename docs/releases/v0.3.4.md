# wocli-music v0.3.4

Windows 任务栏歌词真机嵌入重构、任务栏交互控制按钮与托盘原生音符小图标。

## Windows 任务栏歌词真机嵌入

- **内嵌任务栏而非桌面悬浮**：调用 Win32 `FindWindowW("Shell_TrayWnd")` 与 `GetWindowRect` 动态计算系统任务栏真实坐标与高度，歌词高度适配任务栏（36~40px）并垂直居中精确绘制于任务栏内部，彻底解决此前“歌词显示在桌面悬浮”以及最大化窗口时被遮挡的问题。
- **任务栏原生控制按钮**：在任务栏歌词左侧新增矢量级 **上一首 `⏮`、播放/暂停 `▶ / ⏸`、下一首 `⏭`** 控制按钮，带 1px 高对比防暗阴影与鼠标悬停高亮反馈。
- **直接点击交互控制**：用户可直接在 Windows 任务栏上点击上一首、播放/暂停、下一首进行实时切歌与播放控制，无需打开终端窗口或弹出右键菜单。
- **支持在任务栏上自由拖动**：歌词文本区域通过 Win32 原生 `HTCAPTION` 支持按住鼠标左键在任务栏任意空闲位置自由拖拽停靠并自动记忆位置；双击歌词文本直接唤起终端播放器，右键弹出托盘菜单。

## 系统托盘视觉与图标升级

- **原生金色音乐音符图标**：托盘通知区域不再显示系统默认应用程序白窗，改为通过 Win32 GDI 动态生成的透明背景金黄色音乐音符图标（`♫`），自适应 Windows 10/11 浅色与深色任务栏。
- **清晰单色媒体符号**：右键菜单增加清晰的单色媒体符号（`⏮ 上一首`、`⏭ 下一首`、`▶ 播放 / ⏸ 暂停`），直观清晰且无彩色 Emoji 突兀感。

## 更新方式

v0.3.2 及以上用户可直接在终端执行：

```bash
wocli update
```

或使用一键安装脚本：

```powershell
# Windows PowerShell
irm https://raw.githubusercontent.com/yhan-sun/wocli-music/main/install.ps1 | iex
```

```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/yhan-sun/wocli-music/main/install.sh | bash
```
