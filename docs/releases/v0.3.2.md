# wocli-music v0.3.2

新增分项命令帮助、国内平台备用接口与用户音源导入；播放和下载失败时可自动换源。

## 命令帮助

```bash
wocli help
wocli thelp download
wocli help source
wocli play --help
wocli help keys
```

覆盖播放、下载、队列、收藏夹、配置、更新和音源命令；支持 `--json`，查看帮助不启动后台。

## 国内接口与自动换源

默认先尝试酷我原生解析，再尝试独立的酷我移动备用接口。两者直接访问国内音乐平台，不依赖播放时从 GitHub 拉取脚本。移动接口核对歌曲 ID、音质和时长，音频仍需通过头部、传输完整性及解码检查。

同一首歌解析、下载或解码失败后，排除失败源并继续尝试其他启用源。所有源失败才自动跳过歌曲或报告下载错误，避免重试同一坏地址。播放网络中断仍先重试当前源一次。

```bash
wocli source list
wocli source test kuwo-mobile --id 228908 --quality 128k
wocli source prefer kuwo-mobile
wocli retry --quality 128k
```

## 导入自己的音源

```bash
wocli source add ./qdy.js --name QDY
wocli source add ./my-source.json
wocli source test user-xxxxxxxxxxxx --id 228908 --quality 128k
wocli source prefer user-xxxxxxxxxxxx
```

`source add` 支持本地文件或 HTTP(S) 网址；另有 `list/show/enable/disable/prefer/remove/test`。配置改动在下一次请求生效，无需重启后台。导入后脚本保存在本地，以 SHA256 校验。

内嵌 QuickJS，兼容 LX 的 `kw/musicUrl`、Promise、HTTP、定时器、基础 Buffer、MD5 和 zlib，无需 Node.js。限制执行时间、内存及响应大小。当前搜索和歌曲 ID 仍使用酷我目录；AES/RSA、multipart、Node.js 模块及其他平台的歌曲 ID 暂不支持。

适配参考 [pdone/lx-music-source](https://github.com/pdone/lx-music-source) 和 [LX 官方协议](https://lxmusic.toside.cn/desktop/custom-source)。幻音、长青、QDY、星海脚本通过导入和初始化检查；第三方接口可用性需要另外测试，未将当前异常的第三方接口设为默认源。

## 下载与交互

- 下载到临时目录，完成传输和解码校验后才提交到目标文件；失败的 `--force` 下载保留旧文件。
- 修复预缓冲失败时的完成事件与下一个音源发生竞态。
- `status --json` 新增当前 `source` 和音频加载阶段的 `source_failures`。
- 宽终端显示当前音源 ID，新增 `D` 打开下载任务。

详细配置、HTTP JSON 模板及兼容边界见[音乐源说明](https://github.com/yhan-sun/wocli-music/blob/main/docs/sources.md)。
