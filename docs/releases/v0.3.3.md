# wocli-music v0.3.3

完善 Windows 平台适配、系统托盘与任务栏歌词体验，彻底修复跨平台长驻内存泄漏与网络套接字积压。

## Windows 任务栏歌词与视觉重构

- **无闪烁双缓冲渲染**：Win32 GDI 采用内存双缓冲（`CreateCompatibleDC` + `BitBlt`）并拦截 `WM_ERASEBKGND`，消除歌词变动时的背景闪烁与边缘毛刺。
- **高对比度 8 邻域描边**：在歌词四周绘制深黑 8 邻域阴影，确保在无论极亮还是极暗的复杂桌面壁纸下均清晰易读。
- **自适应任务栏位置**：调用 `SPI_GETWORKAREA` 实时计算当前屏幕任务栏上边缘并水平居中，完美适配 Windows 11/10 各种任务栏高度、DPI 缩放与多显示器设置。
- **分辨率与 Explorer 重启感知**：监听 `WM_DISPLAYCHANGE` 与 `WM_SETTINGCHANGE` 自动重新校准位置；监听 `TaskbarCreated` 消息，资源管理器崩溃或重启时自动恢复托盘图标。
- **状态配色与长歌词省略**：播放时高亮金黄、暂停时典雅银白并保留当前歌词；超出宽度时使用 `DT_END_ELLIPSIS` 优雅呈现省略号。
- **点击穿透**：继续保持 `WS_EX_TRANSPARENT` 穿透特性，不影响用户对桌面图标与底层窗口的正常点击。

## 托盘唤起终端与生命周期

- **打开终端播放器**：托盘菜单“打开控制终端”改用标准控制台宿主自适应启动，直接调起 Windows 11 Windows Terminal 或默认终端窗口，解决此前可能出现的无响应问题。
- **优雅退出防幽灵图标**：Windows 托盘退出前先发送 `WM_CLOSE` 触发 Win32 `NIM_DELETE`，杜绝退出后通知区域残留假死幽灵图标。

## 内存泄漏与网络套接字治理

- **macOS CFString 内存泄漏清零**：修复高频标题更新时遗留的 CoreFoundation 字符串泄露，托盘长期驻留内存平稳维持在 12MB-14MB。
- **Windows TCP TIME_WAIT 积压根除**：优化 IPC 轮询周期，避免本地环回 TCP 短连接积压（解决此前可累积多达数千个 TIME_WAIT 套接字的问题），消除端口耗尽与核心内核内存膨胀隐患。

## 更新

wocli update
```

```

```bash

curl -fsSL https://raw.githubusercontent.com/yhan-sun/wocli-music/main/install.sh | bash
```
