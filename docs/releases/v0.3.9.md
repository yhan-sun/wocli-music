# wocli-music v0.3.9

Windows 歌词条改为真实任务栏子窗口，参考 ANYNC/TaskbarLyrics 的挂接与空间检测方法。

- 清除桌面置顶悬浮逻辑，通过 `SetParent` / `WS_CHILD` 嵌入任务栏；挂接失败时隐藏并报告原因，不回退到桌面悬浮条。
- 经典任务栏预留歌词位置并在隐藏、退出时恢复；现代任务栏后台读取 Explorer 按钮位置，避让图标，空间较窄时收起播放按钮，空间不足时隐藏。
- 处理 DPI、负坐标、过期布局、Explorer 重启与老板模式。Windows 可执行文件增加兼容性与 PerMonitorV2 声明。
- `wocli tray status [--json]` 新增 `lyrics_surface` 挂接、显隐与诊断信息。
- 新增几何布局、快照失效和 Windows 隔离原生窗口测试；随包附带参考项目 MIT 许可。

升级后运行：

```powershell
wocli tray stop
wocli tray start
wocli lyrics-bar on
wocli tray status
```

当前范围为主任务栏横向布局。此实现使用 Win32/GDI 绘制自己的歌词文字，不是 Windows 内置歌词 API；Windows 11 的 Explorer 结构并非稳定扩展协议。隔离原生测试不能代替真实 Explorer、多屏或第三方任务栏实机验收。详见 [任务栏实现与诊断说明](https://github.com/yhan-sun/wocli-music/blob/main/docs/windows-taskbar-lyrics.md)。
