# wocli-music v0.4.14

- Windows 任务栏歌词全面升级 Fluent 原生质感：移除未悬停时的生硬深色背景方块与粗糙 4 邻域黑影，悬停时使用 Windows 11 原生半透明圆角药丸胶囊高亮。
- 自动识别 Windows 系统深色/浅色主题（`SystemUsesLightTheme`），文字与悬停控制按钮颜色自适应，完美适配浅色与深色任务栏。
- 采用 Windows 11 原生字体 `Segoe UI Variable Text` 与系统矢量图标，提升歌词排版抗锯齿与清晰度。
- 任务栏歌词新增左右槽位自适应布局与 CLI 控制（`wocli lyrics-bar [left|right|auto]`）：支持居中图标左侧（小组件旁）或右侧（托盘前）空白定位；auto 模式在右侧空间不足时自动回退至左侧空白。
- 播放器可通过 `wocli update` 直接检测并升级。
