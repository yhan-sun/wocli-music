# Release v0.2.4

wocli-music v0.2.4 修复了 macOS 状态栏图标与歌词显示问题，并在 macOS 上完整实现了原生桌面/任务栏透明悬浮歌词条。

### 核心改进

1. **macOS 状态栏小图标稳定性修复**：
   - 修复 Objective-C ARC 根池 drain 导致 `NSStatusItem`、`NSMenu` 提前销毁的问题，显式 `retain` 核心对象，保证状态栏小图标常驻。
   - 顶部菜单栏标题精简显示，避免在带刘海屏（Notch）的 MacBook 上被系统挤出屏幕。

2. **macOS 原生桌面/任务栏透明悬浮歌词条**：
   - 采用 `NSPanel` 与 `NSTextField` 实现跨桌面、置顶且鼠标穿透的透明歌词条。
   - 停靠在屏幕下方（Dock 上方），高对比度白色大字配黑色阴影，与 `wocli lyrics-bar [on|off|toggle]` 实时联动。

3. **跨平台一键安装器优化**：
   - Windows `install.ps1`：静默进度条并优先使用系统内置 `curl.exe`，彻底解决 SSH 终端下下载挂起与龟速问题。
   - macOS `install.sh`：解压后自动执行 ad-hoc codesign，避免 Apple Silicon 系统的 Gatekeeper 137 SIGKILL 拦截。

### 下载与安装

- **macOS / Linux**:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/yhan-sun/wocli-music/main/install.sh | bash
  ```

- **Windows 10/11**:
  ```powershell
  irm https://raw.githubusercontent.com/yhan-sun/wocli-music/main/install.ps1 | iex
  ```
