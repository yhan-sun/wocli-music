# wocli-music v0.4.12

- 修复 macOS 菜单栏切换控制按钮和老板模式时托盘崩溃的问题。退出时正确移除上一首、播放和下一首按钮。
- 菜单栏打开终端播放器时沿用当前曲库的 `--home`，兼容路径中的空格、引号和其他 shell 特殊字符。
- 下载支持 FAT32 和 exFAT。默认保留同名文件，取消或写入失败时清理未完成的副本。
- 本地 IPC 请求与响应统一使用 64 MiB 上限。通过 10,000 首队列的回归测试，超出上限时返回明确错误。
- 后台未运行时，`wocli stop` 直接返回。`wocli play` 和 MCP `play_music` 未指定歌曲时恢复当前曲目。

运行 `wocli update` 升级，保留曲库和设置。
