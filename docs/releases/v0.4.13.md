# wocli-music v0.4.13

- 新增 Windows 系统歌词卡片开发预览：打开 Windows 11 小组件面板（Win+W）查看歌词；小卡片可暂停／继续，中、大卡片还可切歌。字体、颜色和按钮由 Windows 渲染，不替换任务栏天气文字。
- 加入歌词快照、过期播放操作校验和组件生命周期处理，并保留 v0.4.12 的托盘退出及播放修复。
- 播放器可通过 `wocli update` 更新；Windows 小组件需要另外下载本页的 `wocli-system-widgets-preview-0.4.13-windows-x86_64.zip`，按包内 `PREVIEW.txt` 在开发者模式下注册。普通更新不会安装该组件。

**小组件仍是开发预览**：MSIX 未签名，不能双击安装；跨进程 COM 代理及真实 Windows Widgets 宿主显示尚未验证，主题、DPI、休眠和长期运行也需要实机验收。自动化检查与开发注册不能代替实机验证。

使用前先退出旧 TUI 并执行 `wocli daemon stop`，然后运行配套版本的 `wocli widgets on`，按 Win+W 在面板中添加“wocli 歌词”。普通播放器更新保留曲库和设置。
