# wocli-music v0.3.7

正式发布老板模式及媒体控制，修复快捷键和恢复状态问题。v0.3.6 安装包不包含此前仅在 main 分支提交的老板模式代码。

- 终端快捷键：`Shift+B`、`Ctrl+B` 或 `F12`；伪装时按 `b`、同一快捷键或 `Esc` 恢复。输入框保留大写 B 输入，Ctrl+B/F12 仍有效。
- macOS 全局老板键：`Ctrl+Shift+B`；Windows：`Ctrl+Shift+B` / `Ctrl+Alt+B`。先运行 `wocli tray start`，再用 `wocli tray status` 查看注册结果；冲突会明确报告。
- Linux 可自行将桌面快捷键绑定至 `wocli boss`。
- 老板模式暂停音频、隐藏歌词与歌曲信息，保留中性的 wocli 托盘入口。退出只恢复原先播放/加载中的歌曲。
- 修复重复开启丢失续播、加载状态无法恢复、后台回包导致伪装闪退、按住按键重复切换，以及重试/媒体播放键在伪装期间重新出声。
- 完善中英文文档，补充真实 CLI、终端字节输入和快速切换竞态验证。

已有用户运行 `wocli update` 升级后，退出并重新打开 TUI。若手工替换二进制后后台仍是旧版，请先运行 `wocli daemon stop` 再重开。

终端/复用器可能拦截 Ctrl+B；部分 Mac 键盘需 Fn+F12。系统媒体键是否转发取决于操作系统、终端和当前媒体应用。
