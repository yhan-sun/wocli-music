# wocli-music v0.4.1

Windows 11 任务栏嵌入适配、空闲区域自适应与文字渲染优化。

- 适配 Windows 11 现代任务栏：解耦对传统 `TrayNotifyWnd` 窗口句柄的强依赖，支持直接将歌词子窗口挂接到 `Shell_TrayWnd`。
- 交互控件过滤与空闲槽位寻址：优化 UI Automation 查询条件，直接按按钮、列表项等控件类型过滤，避免遍历整个 XAML 树引发超时；自动在应用按钮（居中或靠左）与右侧系统托盘之间计算空闲区域并按需调整宽度。
- 规范任务栏子窗口挂接生命周期：先应用 `WS_CHILD` 并剥离 `WS_POPUP` 与 `WS_EX_TOOLWINDOW`，再执行 `SetParent` 挂接，遵循 Win32 顶层窗口转子窗口规范，确保挂接后即时生效。
- 优化透明文字渲染质量：调整 GDI 字体渲染为抗锯齿平滑，消除色键透明模式下的边缘次像素彩边。
- 补充 Windows 11 无传统通知区域窗口场景下的布局算法回归测试。
