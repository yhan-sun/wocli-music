# wocli-music v0.4.0

交互控制响应性修复、任务栏歌词默认启动与歌词切换按钮。

- 修复 TUI 搜索与输入框焦点保持问题（#1）：在搜索提交、列表选择、双击播放及各类操作时自动失焦；新增 Tab、Down、Up 快速失焦，彻底解决快捷键（Space 播放/暂停、] 下一首、[ 上一首、m 切换模式）被搜索框捕获的问题。
- 优化播放模式切换：m 快捷键改为直接顺次切换播放方式并弹出即时提示，避免模态弹窗拦截全局快捷键。
- 增加弹窗遮罩外点击关闭支持，避免弹窗阻断底层交互区域。
- 界面增加显式歌词切换与关闭按钮：底栏播放控制增加歌词/关闭按钮；主界面顶栏与歌词面板右上角提供明确的“歌词”、“关闭歌词”与“全屏歌词”按钮。
- 启动 TUI 播放器时默认在后台拉起任务栏与系统托盘歌词服务（遵循 tray 与 lyrics_bar 配置）。
- 补充 TUI 交互响应性、搜索失焦、快捷键调度及歌词按钮状态测试用例。
