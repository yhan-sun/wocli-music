# wocli-music v0.1.0

首个发行版：在终端搜索、播放和管理音乐，无需登录。支持 macOS / Linux，要求 Python 3.11+ 和 mpv。

## 安装

先安装 [uv](https://docs.astral.sh/uv/getting-started/installation/) 和音频后端：

```bash
# macOS
brew install mpv

# Ubuntu / Debian
sudo apt install mpv
```

安装发行包并启动：

```bash
uv tool install --python 3.12 "https://github.com/yhan-sun/wocli-music/releases/download/v0.1.0/wocli_music-0.1.0-py3-none-any.whl"
wocli
```

已有 Python 3.11+ 时也可用 pipx 安装同一 wheel。发行包包含播放器应用代码，mpv 需单独安装；未发布到 PyPI。

## 功能

- 紧凑的曲库、搜索与歌词界面，支持宽屏和窄屏终端。
- 「我喜欢」、自建收藏夹、队列和历史；直接点击「收藏到…」选择收藏夹。
- 顺序、列表循环、单曲循环、随机播放；点击或拖动进度条跳转。
- 音乐在后台播放，退出界面后仍可用命令行控制。
- 音源与歌词分别重试；试听、不完整音频和无音源会明确提示。
- 后台下载、音质与保存目录选择、歌词保存、取消和重试。

按 `/` 搜索，Enter 播放，空格暂停，`c` 收藏，`m` 切换播放方式，`?` 查看快捷键。按 `q` 退出界面；停止播放用 `wocli stop`，停止后台用 `wocli daemon stop`。

## 下载文件

- `wocli_music-0.1.0-py3-none-any.whl`：安装包，适用于支持的 macOS / Linux Python 环境。
- `wocli_music-0.1.0.tar.gz`：源码发行包。
- `SHA256SUMS`：上述两个文件的 SHA-256 校验值。

下载三个文件到同一目录后校验：macOS 执行 `shasum -a 256 -c SHA256SUMS`，Linux 执行 `sha256sum -c SHA256SUMS`。

搜索结果与歌词可用不代表能取得完整音频；部分歌曲受上游接口可用性限制。更多安装方案、截图、操作示例和问题排查见 [README](https://github.com/yhan-sun/wocli-music/blob/v0.1.0/README.md)，完整变化见 [更新日志](https://github.com/yhan-sun/wocli-music/blob/v0.1.0/CHANGELOG.md)。
