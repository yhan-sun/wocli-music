# 0.4.11-alpha.1：Windows 系统小组件歌词开发预览

这个版本尝试通过微软官方 Feed Provider 公告接口，在 Windows 11 天气／小组件入口显示当前歌词或歌曲信息。任务栏文字、颜色、字体和交互由系统绘制，使用系统默认主题。它是 Windows x64 开发预览，不是已完成实机验收的稳定版本。

## 能力和限制

- 新增 `wocli widgets on|off|status`，独立 MSIX 组件读取本机播放器的当前歌词。无需为组件另装全局 .NET；微软 Windows App Runtime 框架依赖随包提供。
- 每 500ms 读取当前状态，最多每 5 秒请求一次最新内容；暂停、停止、老板模式、关闭及失联时请求移除公告。歌曲切换和迟到回调不会重新提交旧歌曲。
- 为每个曲库持久保存系统模式选择，切换曲库或关闭组件不会自动恢复旧 GDI 自绘歌词条。
- 减少歌词解析和跨进程数据复制；限制通信超时、回复长度及诊断文件大小。诊断不保存歌曲文本或授权令牌。
- 修复组件启停竞态、COM 激活参数处理和相对运行目录配置问题。

**该方案不保证常驻或逐句实时同步。** Windows 决定公告是否显示、何时显示及显示时长，并实行配额。`requested_count` 只表示请求；`shown_count` 表示收到过系统展示回调，也不能证明当前仍可见。

微软 Feed Provider 当前仅支持具备相关能力的欧洲经济区设备。Windows 11 25H2 或当前地区设置本身不能证明兼容性。此包未完成真实 Widgets 宿主中的浅／深主题、Explorer 重启、配额、隐私移除和长期内存验收。

## 试用

下载并完整解压 Windows x64 预览 ZIP 到固定目录，先阅读 `PREVIEW.txt`。包内包含匹配的 `wocli.exe`、`Layout`、微软签名运行库依赖、未签名 MSIX、构建信息、校验和及第三方许可／源码。

这是开发注册包，**不能直接双击未签名 MSIX 安装**。开发者模式已经开启时，按照 `PREVIEW.txt` 先安装 `Dependencies` 内的微软框架，再通过 `Add-AppxPackage -Register` 注册 `Layout/AppxManifest.xml`。注册后保留整个 `Layout` 在原路径，并在 Windows Widgets 设置中启用 wocli Feed。

使用此包内的播放器执行：

```powershell
.\wocli.exe widgets on
.\wocli.exe play "歌名 歌手"
.\wocli.exe widgets status --json
```

停止请求公告：`./wocli.exe widgets off`。卸载组件的命令见 `PREVIEW.txt`；共享配置目录不会随卸载删除。稳定版 0.4.10 不具备新的组件通信接口。

详细原理、构建方法及验收边界见 [Windows 任务栏歌词说明](../windows-taskbar-lyrics.md)。
